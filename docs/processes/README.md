# Process Library

The single, findable home for Peter's **repeatable operational processes**. One file per process. If a process matters enough to run more than once, it lives here — not buried in a chat thread.

Each process file follows the same shape: **name · purpose · status · how to run · the rules/factors · training log · automation plan**.

| Process | What it does | Status | Doc |
|---|---|---|---|
| **Adlux Deal Follow-Up Scoring** | Scores every open Pipedrive deal 0–100 on how thoroughly it's been chased, so poorly-followed-up (high-value) deals surface first | ⚙️ Live, semi-automated (hourly recompute); training in progress | [adlux-deal-follow-up-scoring.md](adlux-deal-follow-up-scoring.md) |
| **Pipedrive Prospecting** | Finds new NZ/AU builders, architects, roofers and creates dedup-gated Pipedrive leads with a pending follow-up call | ⚙️ Live, automated | [../pipedrive-prospecting-sop.md](../pipedrive-prospecting-sop.md) |

**Status key:** 📝 drafted · 🙋 manual · ⚙️ semi-automated · ✅ fully automated
